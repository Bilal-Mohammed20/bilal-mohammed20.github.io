04Tools & automation

Tools built to remove the manual work

Tools built to close real operational gaps: from lightweight offline reconciliation checks through to Power BI executive reporting, a monthly SharePoint sync, and its companion Power Apps tool. Four run entirely client-side with no server or install. A self-built support assistant, further down, answers questions about this site itself.

Flagship build

Health Research Activity Dashboard: Data Consolidator

A tool that reconciles multiple REGIS report exports against a master reference dataset into one clean, Power BI–ready file, turning a manual, error-prone reconciliation job into a five-minute upload.

Offline HTML app

Annual Report Reconciliation Tool

Cross-checks MS Teams tracking sheets against REGIS overdue-progress-report data and exports the reconciled result straight into Excel and Word.

Offline HTML app

Weekly Report Generator

Processes multiple REGIS report exports across five reporting sections into a consistent weekly report.

Power BI · multi-page report

REGIS Executive Dashboards

Multi-page Power BI reporting for REGIS (from statewide summary views down to a live, filterable study register), built hands-on for both senior leadership and the team's own internal reporting.

R + VBA · built twice

TAS Form Extractor

Pulls structured answers out of completed Word-based TAS forms (including which checkbox was actually ticked) straight into a formatted Excel sheet.

Shiny app

Research Data Combiner

Merges researcher and PI contact lists into one deduplicated, export-ready table.

Power Automate

Application Status Sync: Power Automate

A monthly flow that reconciles three separate Excel tracking tables into one always-current SharePoint list, upserting each record by Application ID.

Power Apps · retired

Application Email Log: Power Apps

A Power Apps tool for logging every email exchanged about a research application and pulling up its full communication history in one view. Since retired.
